# تطبيق رزق (Jam3iya) - نظام إدارة الجمعيات المالية الدوارة (ROSCA)

تطبيق متكامل مبني باستخدام **Flutter** ومدعوم بخدمات **Firebase** لإدارة الجمعيات المالية التعاونية (الادخار الدوار - Rotating Savings and Credit Association) بسهولة وشفافية وأمان تام، مع دعم كامل للغة العربية والإنجليزية والتصميم التفاعلي (RTL / LTR).

---

## 🌟 الميزات الرئيسية

- **إدارة الجمعيات**: إنشاء وإدارة الجمعيات المالية، تحديد المبالغ الشهرية، مدة الجمعية، وترتيب المستلمين.
- **تتبع الأقساط والدفعات**: تسجيل المدفوعات شهرياً، مراجعة وتأكيد طلبات السداد من قِبل المشرفين، ومتابعة المستحقات.
- **نظام الرتب والصلاحيات**: صلاحيات واضحة ومحددة للمسؤولين (Leader)، المساعدين (Assistant)، والأعضاء (Members).
- **غرف المحادثة الفورية**: دردشة مخصصة لكل جمعية مدعومة بمزامنة فورية عبر Firestore وخاصية الحذف الآمن (Soft Delete) والتحكم بصلاحيات الإرسال.
- **التنبيهات والإشعارات الذكية**: إرسال تذكيرات آلية وفورية بمواعيد السداد عبر Firebase Cloud Messaging (FCM).
- **تصميم مخصص بالكامل**: دعم كامل للاتجاه من اليمين إلى اليسار (RTL) للغة العربية، متجاوب مع مختلف أحجام الشاشات.

---

## 🏗️ البنية البرمجية (Architecture)

- **State Management**: `Provider`
- **Backend & Cloud**:
  - **Firebase Authentication**: تسجيل وإدارة الجلسات ورموز الاسترداد.
  - **Cloud Firestore**: التخزين السحابي الفوري مع قواعد أمان محكمة (`firestore.rules`).
  - **Firebase Cloud Messaging**: إدارة وتسليم الإشعارات السحابية.
  - **Cloud Functions**: الأتمتة المجدولة والتذكيرات التلقائية (`functions/index.js`).
- **Localization**: `easy_localization` (العربية والإنجليزية).

## 🚀 التشغيل والتطوير (Setup & Running)

### المتطلبات الأساسية
- Flutter SDK 3.x
- Dart 3.x
- Android Studio / VS Code
- JDK 17

### خطوات التشغيل
1. تثبيت الحزم:
   ```bash
   flutter pub get
   ```
2. فحص الكود (Static Analysis):
   ```bash
   flutter analyze
   ```
3. تشغيل الاختبارات المؤتمتة (Unit & Widget Tests):
   ```bash
   flutter test
   ```
4. إنشاء نسخة الإنتاج للأندرويد (Release APK):
   ```bash
   flutter build apk --release
   ```

## 🛡️ الأمان وحماية البيانات (Security & Rules)
- تم تأمين قواعد بيانات Firestore عبر `firestore.rules` لمنع القراءة أو الكتابة غير المصرح بها.
- تم ضبط أذونات الشبكة والإنترنت في `AndroidManifest.xml` للعمل المستقر في بيئة الإنتاج.
- لا يتم تخزين مفاتيح حساسة في مستودع الكود.
